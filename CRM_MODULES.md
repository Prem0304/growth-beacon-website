# CRM Modules & Lifecycle Guide — GrowthBeacon CRM

The CRM manages the 18-stage commercial lifecycle:
`Visitor` -> `Lead` -> `Qualification` -> `Sales` -> `Proposal` -> `Deal` -> `Client` -> `Contract` -> `Invoice` -> `Payment` -> `Project` -> `Campaign` -> `Tasks` -> `Content` -> `Reporting` -> `Client Health` -> `Renewal` -> `Retention`.

## Modules Summary
1. **Executive Command Center**: Real-time revenue, conversion rates, MRR, active retainers.
2. **Leads & Pipeline**: Multi-channel lead tracking, auto-scoring (0-100 scale), activity timelines.
3. **Sales Deals**: Kanban & List pipeline views, WON deal conversion workflows.
4. **Clients 360°**: Health scores (Green/Yellow/Red), linked contracts, project feeds.
5. **GST Finance Suite**: GST 18% vs Non-GST toggle, payment recording, balance calculation.
6. **Client Portal**: Dedicated view for client accounts.
